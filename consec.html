푸는 법

연속하는 세 수의 합이 903일 때 가장 큰 수는?

  • 가운데 수를 □라고 하면 세 수는 □ − 1, □, □ + 1
  • 빼고 더한 1이 없어지니 합은 □ + □ + □예요. □ + □ + □ = 903
  • 자리마다 셋으로 나눠요. 900 = 300 + 300 + 300, 3 = 1 + 1 + 1 → □ = 301
  • 세 수는 300, 301, 302 → 가장 큰 수 302
  • 짝수·홀수는 2씩 차이 나요. □ − 2, □, □ + 2

120부터 140까지의 짝수를 모두 더하면?

  • 120, 122, …, 140은 11개예요. 「부터」「까지」는 끝 수도 넣어요.
  • 앞뒤로 짝을 지으면 120 + 140 = 122 + 138 = … = 260이 5쌍, 가운데 130이 남아요.
  • 260 × 5 + 130 = 1300 + 130 = 1430
